Templates

One-tap starting points for common timing needs

A template is a single, ready-configured timer — the right duration and mode already dialed in — that drops you straight into the matching tool page. No setup, no dialing in numbers: pick a template and start immediately.

Template, routine, or fresh tool — which one do you need?

Reach for a template when you already know exactly what you want: a 25-minute study block, a 10-minute meditation, a HIIT 30/30 workout. Templates are quick-start shortcuts — one tap opens the matching tool already configured with the right duration, so you can skip the setup step entirely and get straight to starting the clock.

Reach for a routine instead when what you're doing isn't one timer but several stages in sequence — focus blocks separated by breaks, a sear followed by a simmer, an interval circuit with rounds of work and rest. Routines chain multiple stages together and advance through them automatically; see the Smart Routines page for pre-built sequences.

And when neither fits — you need an odd duration, a different mode, or you just want full manual control — head to the full Tools library and configure a timer from scratch. Templates and routines are shortcuts into that same set of tools, not a replacement for it.
